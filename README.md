# Crypto Hack Economie – eigen tempo

## Lokaal testen
Open `Crypto_Hack_Economie_Eigen_Tempo_DEMO.html` voor een zelfstandige voorbeeldweergave. De demo is niet gekoppeld tussen tabbladen.

## Multiplayer op een server
1. Installeer Node.js 20 of nieuwer.
2. Voer in deze map `npm install` en daarna `npm start` uit.
3. Open http://localhost:3000.
4. De docent kiest de tijd en maakt een gamecode. Leerlingen openen hetzelfde serveradres en voeren hun naam en gamecode in.
5. De docent start de tijd. Leerlingen werken zelfstandig alle 50 vragen door. Na vraag 50 begint een nieuwe ronde, zolang de tijd loopt.

## Hosting op Render
Zet de inhoud van deze map in een GitHub-repository. Maak op render.com een **Web Service** aan, kies de repository, build `npm install`, start `npm start`. Gebruik een Node runtime. Render kent beperkingen voor gratis diensten.

## Belangrijk
Spelkamers staan alleen in servergeheugen en verdwijnen na een herstart. Er is geen accountsysteem, geen permanente opslag, geen herstel van de voortgang na herladen en geen controle op leerlingenidentiteit. Laat leerlingen bijnamen gebruiken. De docent moet het tabblad openhouden om de code terug te kunnen vinden. Het is een oefenproject: test eerst met enkele Chromebooks voordat je het klassikaal inzet.

## Leerstof
50 meerkeuzevragen op basis van de onderwerpen en vaardigheidsdoelen in het aangeleverde leerstencil.
